How to add new furniture or dungeon objects

1. Add the furniture template in:
   src/scripts/content/furniture/dungeon-furniture-pack.js

Use DungeonContent.register("furniture", id, template):

(() => {
window.DungeonContent.register("furniture", "myStatue", {
  name: "Stone Statue",
  kind: "furniture",
  tags: ["furniture", "old-guardroom"],
  width: 1,
  height: 1,
  blocksMovement: true,
  interactable: true,
  description: "A cracked stone statue. It blocks movement.",
});
})();

Important fields:
name: Display name.
kind: Usually "furniture", "container", "trap", or "portal".
tags: Used by themes to allow or block this furniture.
width and height: Size in grid squares.
blocksMovement: true if heroes and monsters must path around it.
interactable: true if it should show actions in the right-click panel.
description: Text shown in the right-click info panel.

2. Load the file in index.html before app.js if it is a new file.

3. Make it eligible for a theme.

Themes use furnitureTagGroups:

furnitureTagGroups: [
  ["furniture", "old-guardroom"],
  ["chest"],
]

A furniture object can spawn when it matches at least one full tag group.

4. Give it a spawn chance.

In the theme file:

furnitureSpawnChances: {
  myStatue: 0.12,
}

5. Add placement logic if the existing object placement does not know this type yet.

The shared placement function is createDungeonObjects in src/scripts/app.js.
It already handles tables, big rocks, chests, traps, and portals. A new shape or special rule needs a small placement branch there.

Useful helpers:
objectCells(object): all grid cells occupied by the object.
blockingObjectKeys(): movement-blocking object cells.
objectAt(position): object on a tile.
objectTemplate(type): reads the furniture/trap template.
showDungeonObjectInfo(object): right-click info panel.
randomOpenCell(cells, blockedKeys): pick a legal free tile.
wallAdjacentRoomCells(room): good chest-like placement candidates.

6. Chests and loot

Use type "chest" for normal dungeon chests. They automatically get randomChestLoot and may get chest traps.

Custom containers need custom interaction code in showDungeonObjectInfo/takeObjectItem unless they follow the existing chest shape:

{
  id: objectId("chest"),
  type: "chest",
  position: { ...position },
  items: randomChestLoot(2),
}
