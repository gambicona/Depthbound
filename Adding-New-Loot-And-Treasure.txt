How to add new loot, treasure, and magic items

1. Choose the right item file

Normal equipment and potions:
src/scripts/content/items/equipment.js

Magic weapons and armor:
src/scripts/content/items/magic_items.js

Magic rings, amulets, boots, cloaks, bracers, gauntlets, helms:
src/scripts/content/items/magic_accessories.js

Valuables, gems, art objects, and trade goods:
src/scripts/content/items/treasure.js

2. Load new item files

If you create a new item file, add it to index.html after equipment.js and before app.js:

<script src="src/scripts/content/items/my-loot-file.js" defer></script>

3. Treasure items

Use the helper in treasure.js:

gemstone("Amethyst", 100, "purple", "Violet quartz associated with nobility and wards.");
artObject("Gold Idol", 2500, "gold", "A palm-sized idol with old temple marks.");
valuable("Silver Trade Bar", 5, "silver", "A stamped trade bar.", { stackable: true });

Treasure should have:
type: "treasure"
tags: include "treasure"
treasure.valueGp: controls sell value and spawn tier
treasure.dropWeight: optional; lower means rarer

Treasure sells at full value.

4. Magic weapons and armor

Use registerMagicWeapon or registerMagicArmor in magic_items.js:

registerMagicWeapon("magic-dagger-plus-1", "dagger", "Dagger +1", "uncommon", 500, {
  enhancementBonus: 1,
  description: "A balanced dagger with a faint silver edge.",
});

registerMagicWeapon("magic-ember-dagger", "dagger", "Ember Dagger", "uncommon", 850, {
  extraDamage: { count: 1, sides: 4, type: "fire" },
  description: "Deals normal dagger damage plus 1d4 fire damage.",
});

Magic weapons should use:
store.buyable: false
tags: "magic", "magic-item", "loot:magic"
loot.priceGp: controls dungeon tier
loot.dropWeight: optional; lower means rarer
magic.attackBonus, magic.damageBonus, magic.extraDamage

5. Magic accessories

Use registerMagicAccessory in magic_accessories.js:

registerMagicAccessory("magic-ring-guardian", "Ring of the Guardian", ["ring1", "ring2"], "uncommon", 1200, {
  effects: { acBonus: 1 },
  description: "Grants +1 AC while equipped.",
});

Supported accessory effects:
abilityScoreBonuses: { str: 2, dex: 1 }
abilityScorePenalties: { dex: -2 }
abilityScoreCaps: { str: 22 }
maxHpBonus
acBonus
initiativeBonus
speedBonusFeet
resistances
vulnerabilities
attackBonus
damageBonus
extraDamage

Usable accessories can define use with charges. Charges refresh on "shortRest", "longRest", "newDungeon", or "home".

6. Making loot spawn

The app now uses shared random loot logic:
normal monsters: very small chance for potion/equipment/treasure/magic
bosses: high chance for treasure and meaningful chance for magic
chests: small chance for treasure and rare chance for magic

Higher-level dungeons can roll higher-value loot. The cap is based on party level category:
category 1: up to about 2,500 gp
category 2: up to about 9,000 gp
category 3: up to about 35,000 gp
category 4: up to about 90,000 gp
category 5+: up to about 200,000 gp

To make an item eligible for magic loot, give it:
tags: ["loot:magic", "magic-item"]
loot: { priceGp, dropWeight, rarity }

To make treasure eligible, give it:
type: "treasure"
treasure: { valueGp, dropWeight }

7. Guaranteed or monster-specific drops

Add extraLoot to a monster template:

extraLoot: [
  { kind: "item", itemId: "gem-amethyst", quantity: 1 },
  { kind: "randomEquipment" },
]

Use this sparingly. Most loot should come from the shared loot logic.

8. Testing

Enable Adminmode, open inventory, expand Item Vault, and search for the item name or tag.
Magic and treasure are loot-only for merchants, but admin can still add them for testing.
