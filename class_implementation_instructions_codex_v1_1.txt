GAME DUNGEON CRAWLER - BASIC CLASS IMPLEMENTATION INSTRUCTIONS
Version: 1.1
Revision note: spell acquisition changed so full casters choose 2 spells at level 1 and +1 spell each level; Paladin and Ranger choose 1 spell at level 1 and +1 spell on each later odd level.
Scope: all 12 base classes, no subclasses, combat-focused implementation, levels 1-20
Target reader: Codex / implementation agent

============================================================
0. HIGH-LEVEL DESIGN GOAL
============================================================

Implement the 12 basic D&D-like classes for the Game Dungeon Crawler project in a slim, combat-first way.

The implementation should NOT try to recreate full tabletop D&D. The game is a tactical dungeon crawler. Therefore:

- Keep combat mechanics.
- Strip or defer social, exploration, crafting, language, tool, and ribbon features.
- Do not implement subclasses yet.
- Do not implement the full D&D spell list.
- Use the slim spell package already designed for this project.
- Use the spell point variant instead of spell slots.
- Make class data highly structured and easy to extend later.
- Avoid hardcoding behavior directly into UI screens. Put class rules into data/services where possible.

Important project note:
This Game Dungeon Crawler project is separate from Exuro. Do not use Exuro lore, Dreamblight lore, Eisenbrand, Black Crypt, etc.

============================================================
1. GLOBAL ASSUMPTIONS
============================================================

D&D baseline:
- Use a 5e-2014-style class chassis as the reference point.
- No subclasses are implemented for now.
- Subclass levels should either be empty placeholders or receive temporary generic balance compensation only if explicitly marked in this document.

Playable levels:
- Character level 1 through 20.

Combat-only scope:
Keep:
- Attacks
- Damage
- Healing
- Temporary HP
- Armor / defense
- Saving throws
- Movement boosts
- Extra attacks
- Reactions
- Buffs
- Debuffs
- Control effects
- Pets / summons where class-defining
- Spellcasting
- Spell points
- Short-rest / long-rest recharge mechanics if the game has rests

Strip or defer:
- Tool proficiencies
- Languages
- Roleplay-only knowledge features
- Ritual casting unless already supported
- Mundane travel/exploration bonuses
- Crafting
- Lifestyle/economy features
- Detailed deity/patron/oath/circle/school narrative mechanics

Ability score names:
Use this exact order everywhere unless the existing codebase already has a different canonical order:
[STR, DEX, CON, INT, WIS, CHA]

Standard array:
[15, 14, 13, 12, 10, 8]

Ability score improvements:
- ASI means the player can increase one ability by +2 or two abilities by +1.
- No ability score should normally exceed 20 through ASIs.
- Feats are not required for the first implementation.
- If feats exist later, ASI levels can offer ASI or feat.

2. GLOBAL SPELL POINT MODEL
============================================================

Spell point cost by spell level:

Spell Level 1 = 2 SP
Spell Level 2 = 3 SP
Spell Level 3 = 5 SP
Spell Level 4 = 6 SP
Spell Level 5 = 7 SP
Spell Level 6 = 9 SP
Spell Level 7 = 10 SP
Spell Level 8 = 11 SP
Spell Level 9 = 13 SP

Upcasting:
- A spell may be cast at a higher spell level if the caster's max cast level allows it.
- The player pays the higher spell level's SP cost.
- Apply the upcast scaling listed in the spell definition.
- Since the slim spell package mostly contains spell levels 1-3, higher-level spellcasting mostly means stronger upcasts.

Spell acquisition / chosen spell model:
- Do not unlock entire class spell lists automatically. Characters should gain a controlled number of chosen spells from their class slim spell list.
- A chosen spell means the spell is available in the character's combat spell UI and can be cast if the character has enough spell points and the spell's base level is not above the character's current max spell level.
- Chosen spells are persistent character choices, not daily prepared loadouts. The system may later add respec, retraining, or preparation, but the first implementation should use persistent chosen spells.
- If a class has already chosen all spells available in its slim spell list, further spell-choice events do nothing unless the spell list has been expanded.
- On a level-up spell-choice event, the character may choose any spell from the class list whose base spell level is less than or equal to the class's current max spell level.
- If no eligible unchosen spells exist at that level, the system should store an unused spell-choice credit or silently skip the choice. Storing a credit is better for future expanded spell lists.

Full caster chosen spell progression:
- Applies to Bard, Cleric, Druid, Sorcerer, and Wizard.
- Level 1: choose 2 spells from the class slim spell list.
- Every level after level 1: choose +1 additional spell.
- With the current 10-spell slim lists, a full caster reaches all 10 class spells at level 9. From level 10 onward, no additional spells are gained unless the list is expanded.

Half caster chosen spell progression:
- Applies to Paladin and Ranger.
- Level 1: choose 1 spell from the class slim spell list.
- Later odd levels only: choose +1 additional spell at levels 3, 5, 7, 9, 11, 13, 15, 17, and 19.
- With the current 10-spell slim lists, a half caster reaches all 10 class spells at level 19.
- Because this project grants Paladin and Ranger a level-1 spell choice, Paladin and Ranger spellcasting starts at level 1 in this game, even though tabletop D&D normally starts them later. The half-caster spell point table gives them 2 SP at level 1 so the selected spell is usable.

Warlock chosen spell progression:
- Warlock is a pact caster, not a normal full caster or half caster. Do not apply the full-caster or half-caster chosen spell progression automatically.
- Recommended first implementation: Warlock chooses 2 pact spells at level 1, then +1 pact spell at levels 3, 5, 7, 9, 11, 13, 15, and 17. This gives Warlock all 10 slim pact spells by level 17.
- Warlock spell use still follows the pact SP table and pact casting rules.

============================================================

6. WARLOCK SPELL DEFINITIONS TO ADD
============================================================

The previous slim spell file did not include Warlock. Add these Warlock spells using the same architecture and conventions.

armor_of_agathys
- Spell level: 1
- Cost: 2 SP, or higher when upcast
- Type: defensive buff / retaliation
- Target: self
- Duration: encounter or until temporary HP is depleted
- Rule: Gain 5 temporary HP per spell level. While any of these temporary HP remain, a melee attacker that hits the caster takes cold damage equal to the temporary HP amount originally granted by the current cast tier.
- Upcast: +5 temporary HP per spell level. Retaliation damage scales with the cast tier.

arms_of_hadar
- Spell level: 1
- Cost: 2 SP
- Type: close AoE damage / control
- Target: enemies adjacent or in a small radius around caster
- Rule: Enemies save. On fail, take 2d6 necrotic damage and cannot make reactions or opportunity attacks until their next turn. On success, take half damage and no control rider.
- Upcast: +1d6 damage per spell level.

hex
- Spell level: 1
- Cost: 2 SP
- Type: mark / damage debuff
- Target: one enemy
- Duration: 3 rounds, concentration
- Rule: The caster's attacks and damaging spells deal +1d6 necrotic damage to the hexed target once per hit or damage instance, depending on engine simplicity. The target also suffers a small penalty to one chosen defense/save category if that exists. If that does not exist, omit the secondary penalty.
- Upcast: increase duration or add +1d6 every 2 spell levels above 1st. Do not let it outscale Hunter's Mark too strongly.

hellish_rebuke
- Spell level: 1
- Cost: 2 SP
- Type: reaction damage
- Trigger: caster is damaged by an enemy within range
- Rule: The triggering enemy saves. On fail, it takes 2d10 fire damage. On success, half damage.
- Upcast: +1d10 damage per spell level.

cause_fear
- Spell level: 1
- Cost: 2 SP
- Type: single-target debuff
- Target: one enemy
- Rule: Target saves. On fail, it becomes Frightened for 2 rounds. Frightened means attack penalty while the source is visible and cannot willingly move closer to source.
- Upcast: +1 target per spell level.

darkness
- Spell level: 2
- Cost: 3 SP
- Type: area control
- Target: area
- Duration: 3 rounds, concentration
- Rule: Create magical darkness. Ranged attacks into, out of, or through the area have severe accuracy penalty. Units inside count as heavily obscured. Creatures with Devil's Sight or equivalent ignore the penalty.
- Upcast: larger area or +1 round duration.

hold_person
- Use the already defined Hold Person spell.

misty_step
- Use the already defined Misty Step spell.

hunger_of_hadar
- Spell level: 3
- Cost: 5 SP
- Type: AoE damage / control hazard
- Target: area
- Duration: 3 rounds, concentration
- Rule: Create a void zone. Enemies inside are Blinded while within the area. Enemies entering or starting their turn inside take 2d6 cold damage. Enemies ending their turn inside take 2d6 acid damage. If two damage events are too complex, simplify to 4d6 mixed damage once per round, save for half.
- Upcast: +1d6 total damage per spell level or larger area.

vampiric_touch
- Spell level: 3
- Cost: 5 SP
- Type: sustained melee spell damage / self-healing
- Duration: 3 rounds, concentration
- Rule: Each round, the caster may make a melee spell attack against one adjacent enemy. On hit, deal 3d6 necrotic damage and heal for half the damage dealt.
- Upcast: +1d6 damage per spell level.

7.1 BARBARIAN
------------------------------------------------------------

Predefined ability array:
[15, 13, 14, 8, 12, 10]
STR 15, DEX 13, CON 14, INT 8, WIS 12, CHA 10

Starter gear: weapons/armor/ammo only
Always granted:
- 4 javelins
Choice group A:
- greataxe
- any martial melee weapon
Choice group B:
- 2 handaxes
- any simple weapon
Armor:
- none by default

Spell list:
- none

Combat identity:
- Durable melee striker.
- High HP and physical resistance through Rage.
- Strong damage consistency.
- Uses Reckless Attack to trade defense for accuracy.

Core resources:
- Rage uses per long rest, unless your game uses encounter-based resources.
- If the dungeon crawler has few long rests, consider making Rage recover partially on short rest or per encounter.

Rage table:
Level 1-2: 2 uses, +2 melee damage
Level 3-5: 3 uses, +2 melee damage
Level 6-8: 4 uses, +2 melee damage
Level 9-11: 4 uses, +3 melee damage
Level 12-15: 5 uses, +3 melee damage
Level 16: 5 uses, +4 melee damage
Level 17-19: 6 uses, +4 melee damage
Level 20: unlimited uses, +4 melee damage

Rage implementation:
- Activation: bonus action or equivalent quick action.
- Duration: 10 rounds or until combat ends.
- Ends early if the barbarian is incapacitated.
- While raging:
  - Gain resistance to physical weapon damage: bludgeoning, piercing, slashing.
  - Gain bonus damage on Strength-based melee weapon attacks.
  - Cannot cast or concentrate on spells, if spellcasting ever applies.

Level progression:
Level 1: Rage, Unarmored Defense
Level 2: Reckless Attack, Danger Sense
Level 3: Rage uses increase to 3. No subclass feature.
Level 4: ASI
Level 5: Extra Attack, Fast Movement
Level 6: Rage uses increase to 4. No subclass feature.
Level 7: Feral Instinct
Level 8: ASI
Level 9: Brutal Critical 1 extra weapon die, Rage Damage +3
Level 10: No subclass feature
Level 11: Relentless Rage
Level 12: ASI, Rage uses increase to 5
Level 13: Brutal Critical 2 extra weapon dice
Level 14: No subclass feature
Level 15: Persistent Rage
Level 16: ASI, Rage Damage +4
Level 17: Brutal Critical 3 extra weapon dice, Rage uses increase to 6
Level 18: Indomitable Might
Level 19: ASI
Level 20: Primal Champion, unlimited Rage

Feature notes:
- Unarmored Defense: when not wearing armor, defense/AC can use DEX + CON style scaling.
- Reckless Attack: player may choose to gain advantage/accuracy bonus on melee Strength attacks this turn; attacks against the barbarian gain advantage/accuracy bonus until next turn.
- Danger Sense: advantage/bonus on Dexterity saves against visible effects such as traps, explosions, breath attacks.
- Extra Attack: two attacks when taking the Attack action.
- Fast Movement: increase movement if not wearing heavy armor.
- Feral Instinct: initiative bonus; cannot be easily surprised if conscious.
- Relentless Rage: when dropped to 0 HP while raging, make a save/check to stay at 1 HP. Difficulty increases after each use until rest.
- Persistent Rage: Rage no longer ends early except by unconsciousness, death, or voluntary end.
- Indomitable Might: if Strength check would be lower than Strength score/mod threshold, treat as minimum. If the game has no ability checks, convert to +2 melee shove/grapple checks.
- Primal Champion: STR +4 and CON +4, max increases accordingly.

Balance notes:
- Barbarian is simple and strong at low levels.
- Watch physical resistance carefully. It can double effective HP against weapon-heavy enemies.
- Add more elemental/magical enemy damage at high levels so Barbarian is not unkillable.
- Without subclasses, Barbarian has empty levels at 10 and 14. This is acceptable for a first pass but may feel flat.
- Optional later compensation: add generic Rage upgrades at levels 10 and 14.

- Bard's personal damage should stay lower than Wizard/Sorcerer.
- Magical Secrets can break class identity. For v1, limit choices to 2-4 curated options if full cross-class selection is too risky.

  - Level 11: destroy standard low-tier undead
  - Level 14: destroy elite low-tier undead
  - Level 17: destroy strong mid-tier undead
- Blessed Strike baseline: This is a recommended no-subclass compensation because Cleric domains normally provide combat scaling. Once per turn, Cleric deals +1d8 radiant on a weapon hit or damaging cantrip/spell attack. Increase to +2d8 at level 14.
- Divine Intervention Lite: if implemented, make it a powerful once-per-long-rest emergency button, not an open-ended wish. Examples: mass heal, radiant nuke, party cleanse.

Balance notes:
- Cleric can easily become too good because it has armor, healing, Spirit Guardians, and good damage.
- Spirit Guardians should require concentration and should not stack with similar auras.
- Healing Word and Mass Healing Word are strong because they are quick actions. Limit quick-action spell usage if action economy becomes too generous.
- Without domains, Cleric loses flavor. Later, subclasses should mostly add identity, not raw healing power.

- Pact of the Chain: gain familiar/pet. Keep weaker than Ranger Companion.
- Pact of the Tome: gain extra cantrip-like magical options. If cantrips are not implemented broadly, defer.

Feature notes:

- Patron features are not implemented yet.
- Mystic Arcanum should be implemented only after high-level encounter balance exists, or as simple placeholder ultimates.

Balance notes:
- Warlock's balance depends on rest frequency. If short rests are common, Warlock is very strong. If short rests are rare, Warlock is weak.

- Darkness + Devil's Sight can be oppressive. Ensure it affects allies too, or limit duration/area.

10. BALANCING TIPS ACROSS ALL CLASSES
============================================================

No-subclass warning:
- Several classes lose major power and identity without subclasses.
- The most affected are Fighter, Rogue, Cleric, Druid, Sorcerer, Warlock, Paladin, Ranger, and Monk.
- Barbarian, Bard, Wizard remain more complete from base features, but still lose some flavor.

Recommended temporary compensation approach:
- Do not add complex subclass systems yet.
- Where needed, add light generic compensation to preserve class fantasy:
  - Cleric: Blessed Strike baseline at level 8.
  - Druid: scaling Combat Wild Shape tiers.
  - Ranger: base Ranger Companion.
  - Fighter: optional generic maneuvers later.
  - Paladin: optional level 20 Holy Champion placeholder.
- Mark these as temporary so they can be removed or migrated when subclasses exist.

Action economy is more important than raw numbers:
- Bonus/quick actions are extremely valuable.
- Reaction spells like Shield and Hellish Rebuke must obey one reaction per round.
- Pet attacks should not be fully free.
- Quickened Spell and Healing Word need clear action rules.

Concentration:
- Implement concentration early if possible.
- Many powerful spells depend on it: Bless, Bane, Shield of Faith, Entangle, Faerie Fire, Web, Haste, Spirit Guardians, Spike Growth, Hunter's Mark, Hex, Darkness.
- Only one concentration effect per caster at a time.
- Taking damage should force a concentration save/check if the engine supports it.
- If concentration is not implemented, reduce durations and/or increase SP costs.

Control effects:
- Stunned, Held, Restrained, Frightened, Prone, Blinded, Exposed, Obscured must have consistent shared definitions.
- Bosses should have resistance to hard control.
- Suggested boss rule: first hard-control failure per combat is downgraded to Slowed/Exposed, or bosses have limited legendary resistance charges.

Healing:
- Healing can slow combat if too strong.
- Healing Word is ranged and quick, so keep numbers modest.
- Cure Wounds should heal more but require adjacency/action.
- Mass Healing Word should be useful but not reset the whole party from near death repeatedly.

Damage scaling:
- Martial classes scale mostly through Extra Attack, Sneak Attack, Rage damage, Divine Smite, and Improved Divine Smite.
- Casters scale through SP budget, max spell level, AoE, and upcasting.
- Watch level 5 carefully: Extra Attack and 3rd-level spells both spike here.

Rests/resources:
- If the game has long dungeons with few rests, long-rest classes will feel weak.
- If the game has many short rests, Warlock, Fighter, and Monk become stronger.
- Decide on a rest model early and tune resource recovery around it.

Recommended first balance target:
- Barbarian/Fighter/Paladin: durable frontline.
- Rogue/Ranger/Monk: mobile striker.
- Wizard/Sorcerer/Warlock: damage/control caster.
- Cleric/Druid/Bard: support/control hybrid.
