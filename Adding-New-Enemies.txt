How to add a new enemy and make it spawn

1. Create or update a monster content file in:
   src/scripts/content/monsters/

2. Register the monster with DungeonContent:

(() => {
window.DungeonContent.register("monsters", "myMonsterId", {
  name: "My Monster",
  role: "Short description shown in admin tools",
  tags: ["undead", "old-guardroom"],
  maxHp: 12,
  category: 1,
  xp: 50,
  ac: 13,
  attackBonus: 4,
  damage: { count: 1, sides: 6, bonus: 2, type: "piercing", label: "1d6 + 2 piercing" },
  initiativeBonus: 2,
  speedFeet: 30,
  behavior: "melee",
  token: "M",
});
})();

3. Load the file in index.html before app.js:

<script src="src/scripts/content/monsters/my-monster.js" defer></script>

4. Make it eligible for a dungeon theme.

Themes now use tag groups as the easiest spawn filter:

monsterTagGroups: [
  ["undead", "old-guardroom"],
]

A monster can spawn when it matches at least one full tag group. You can still use explicit monster ids if a theme defines them, but tags are easier to maintain.

5. Categories control when it can spawn:
   category 1: hero levels 1-2
   category 2: hero levels 3-4
   category 3: hero levels 5-6
   and so on.

Lower-category monsters can still appear in higher-level dungeons and may be scaled. Higher-category monsters should not appear in low-level dungeons.

6. Behaviors currently supported:
   melee: moves toward a chosen target and attacks in melee.
   rangedKiter: tries to attack at range while repositioning inside its room.
   swarm: several copies spawn together and focus one nearby party target.

7. Bosses

Add boss tags such as ["boss", "undead", "old-guardroom"] and make sure the theme's bossMonsterTagGroups can match them:

bossMonsterTagGroups: [
  ["undead", "old-guardroom", "boss"],
]

Bosses spawn in the exit room when the party needs a dungeon boss, currently at the higher level of a category band such as level 2, 4, 6, or 8.

8. Loot

Normal monsters use the shared loot logic in app.js and should not need custom loot.

For guaranteed or special drops, add extraLoot to the monster:

extraLoot: [
  { kind: "item", itemId: "gem-amethyst", quantity: 1 },
  { kind: "randomEquipment" },
]

Bosses already have a much higher chance to drop treasure and magic items than normal monsters.
