Serious Cleanup Toolchain

This studio is good for quick in-game character color. A dedicated audio editor is useful when a take has room noise, harsh S sounds, mouth clicks, or needs batch cleanup across many files.

  • FFmpeg: normalize volume, filter rumble/hiss, compress dynamics, convert to compact WebM.
  • Audacity/Reaper: visual noise repair, de-essing, mouth-click removal, formant/pitch plugins, reusable batch chains.
  • Recommended workflow: keep raw local, export processed .webm, commit only final files plus manifest.
