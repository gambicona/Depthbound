Loot Drop System
================

This note explains the current random loot rules used by monster drops and dungeon chest/furniture loot.


Core Idea
---------

Random loot value is now gated by average party level, not by dungeon category alone.

The system still uses loot category for some chance scaling, especially monster and boss drop chances, but the value of the item that can be picked comes from the party-level budget table in:

src/scripts/app/combat-map.js

Look for:

lootBudgetsByLevel
lootBudgetForPartyLevel()
maxLootValueGpForKind()


Average Party Level
-------------------

The game computes average party level from the active party. Solo level 1 is average level 1. A party with level 4 and level 6 heroes averages to level 5.

This average level decides the allowed maximum value for:

- treasure
- normal equipment
- magic loot
- healing potion tier

Treasure Drops
--------------

Treasure includes gemstones, art objects, and valuable trade goods from:

src/scripts/content/items/treasure.js

When a treasure drop is rolled, the game filters out anything above the party's treasure cap.

Example:

- Average party level 1 can find treasure up to 100 gp.
- Average party level 3 can find treasure up to 500 gp.
- Average party level 5 can find treasure up to 1000 gp.

After filtering, treasure is weighted cheaper-first. The default treasure weight is:

1000 / sqrt(valueGp)

This means expensive treasure is possible once unlocked, but cheaper treasure remains more common.


Magic Loot
----------

Magic items are filtered by the party's magic cap.

At level 1 the magic cap is 0 gp, so random magic loot should not produce normal magic items. At level 2 the first low-priced magic items can begin to appear. The cap then rises gradually.

Magic item drop weight comes from each magic item definition. Most magic weapons, armor, and accessories use a price-and-rarity formula:

base weight / (rarity penalty * sqrt(priceGp))

So cheaper and lower-rarity magic items are more likely than expensive or rare ones.


Normal Equipment
----------------

Normal equipment drops are filtered by the party's equipment cap.

The equipment pool excludes:

- healing-use items
- magic loot
- treasure
- items marked not buyable

After filtering, normal equipment uses a cheaper-first weight:

1 / sqrt(itemValueGp)


Healing Potions
---------------

Potion drops are filtered by the party's potion cap.

Current potion prices:

- Potion of Healing: 10 gp
- Potion of Greater Healing: 100 gp
- Potion of Superior Healing: 500 gp
- Potion of Supreme Healing: 5000 gp

After filtering, potion weights are:

- Potion of Healing: 75
- Potion of Greater Healing: 18
- Potion of Superior Healing: 6
- Potion of Supreme Healing: 1

So higher-tier potions unlock by level, but lower-tier potions remain common.


Monster Loot Chances
--------------------

Monster loot is rolled in:

createLootForMonster()

Normal monsters roll independently:

- Healing potion: 5%
- Normal equipment: 2%
- Treasure: 2%
- Magic item: 1% at lower categories, up to 2% at higher categories

Boss monsters roll independently:

- Healing potion: 30%
- Normal equipment: 18%
- Treasure: 75%
- Magic item: 28% to 55%, scaling with category

Important: monster category can still affect whether loot appears, but party level decides whether the chosen item is allowed by value.


Chest and Furniture Loot
------------------------

Random chest/furniture loot is rolled in:

randomChestLoot()

The base chest pool includes:

- allowed healing items
- ammunition
- allowed buyable weapons

This base pool is filtered by the same party-level budget.

Chests can also add treasure and magic:

- Treasure chance: 16% + 2.5% per average party level, capped at 50%
- Magic chance: -0.5% + 1.5% per average party level, capped at 14%

Those added treasure and magic items still use the same party-level value caps.


Category Still Exists
---------------------

The older category system is still used in other parts of the game.

Category is:

ceil(averagePartyLevel / 2)

Category is still useful for monster selection, monster scaling, room difficulty, and some drop chance scaling. It should not be used as the main item-value gate anymore.


Design Rule
-----------

If a new random loot source is added, it should do two things:

1. Decide whether loot appears using its own chance logic.
2. Pick the item through the shared party-level budget helpers.

That keeps reward pacing smooth while still allowing bosses, special chests, and dangerous rooms to feel more generous.
