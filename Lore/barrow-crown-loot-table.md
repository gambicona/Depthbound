## Notes

- `custom-item-1` is dungeon-local, so its name changes per dungeon: Broken Oath Seal in D2, Bone Key in D3, Grave-Market Ledger in D4, and Funeral Bell in D5.
- Monster fixed drops are only the `extraLoot` listed in the dungeon JSON. Equipped monster weapons/armor are not automatically listed as drops by `createLootForMonster`; random equipment is rolled separately.
- The random equipment filter is broad in the current code. It checks for non-healing, non-magic, non-treasure, buyable-not-false items, so it can include things that are not ordinary weapons or armor if they pass those flags.
