SLIM SPELL IMPLEMENTATION INSTRUCTIONS
Game Dungeon Crawler - Player Spell System, Levels 1-6

Purpose
=======
Implement a slim, combat-focused spell system inspired by classic D&D spellcasting, optimized for a dungeon crawler. The goal is not to reproduce the full tabletop rules. The goal is to capture each class's fantasy with a manageable number of reusable combat spell templates.

The initial implementation should cover only player character levels 1-6 and only the following spellcasting classes:

- Cleric
- Druid
- Wizard
- Bard
- Sorcerer
- Paladin
- Ranger

The system should focus on combat-relevant spells only:

- Damage spells
- Area damage spells
- Healing spells
- Buffs
- Debuffs
- Battlefield control
- Terrain hazards
- Mobility and defense tools
- Weapon-enhancing smite/strike effects

Do not prioritize non-combat utility, narrative-only magic, exploration-only spells, divination, rituals, long-duration travel spells, food/water spells, or purely social spells in the first pass.

Important Design Direction
==========================
This spell system should be much slimmer than normal D&D. Each class receives a curated list of 10 iconic spells that represent the class flavor. These are not meant to be exhaustive class spell lists.

The implementation should be data-driven wherever possible. Avoid creating one-off bespoke logic for every spell unless the spell absolutely requires it. Most spells should be expressible through shared spell templates such as:

- Single-target damage
- Multi-hit damage
- Burst area damage
- Cone area damage
- Line area damage
- Single-target healing
- Multi-target healing
- Ally buff
- Enemy debuff
- Disable/control
- Sustained area hazard
- Terrain modifier
- Weapon attack rider
- Reaction defense
- Teleport/mobility
- Summoned recurring attack

The spell definitions should be easy to rebalance later. Damage dice, duration, range, area size, number of targets, status effects, and upcast scaling should be stored as editable spell data rather than hard-coded into game logic whenever feasible.

Spell Point Variant
===================
Use a spell point system instead of individual spell slots.

For levels 1-6, the game only needs to support spell levels 1-3 for full casters and spell levels 1-2 for half casters.

Spell point costs:

- 1st-level spell: 2 spell points
- 2nd-level spell: 3 spell points
- 3rd-level spell: 5 spell points

Upcasting means the player pays the spell point cost of the higher spell level and the spell receives its listed scaling benefit.

Examples:

- A 1st-level spell cast at 1st level costs 2 spell points.
- A 1st-level spell cast at 2nd level costs 3 spell points.
- A 1st-level spell cast at 3rd level costs 5 spell points.
- A 2nd-level spell cast at 3rd level costs 5 spell points.

The UI should clearly show:

- Base spell level
- Current selected cast level
- Spell point cost at selected level
- What changes when upcast
- Whether the spell requires concentration
- Whether the spell is an action, quick action, reaction, or weapon-rider effect

Scope Limits for Initial Implementation
=======================================
For the first pass, implement only spells available in the curated lists below.

Do not implement:

- Every official D&D spell
- Non-combat utility spell lists
- Ritual casting
- Spell components
- Material costs
- Spell schools unless useful for internal classification
- Complex tabletop edge cases
- Counterspell interactions unless already part of the combat engine
- Multiclass spellcasting unless the game already supports multiclassing
- Full subclass-specific expanded spell lists

If subclasses exist, subclass-granted spells can be added later as an additional layer. For now, implement the base class spell kits.

Core Spell Properties
=====================
Each spell should have at least the following conceptual properties in the game's spell data:

- Spell name
- Class availability list
- Base spell level
- Minimum character level required, if the game gates by character level
- Spell point cost by cast level
- Action type
- Target type
- Range category
- Area shape, if applicable
- Area size, if applicable
- Damage type, if applicable
- Healing formula, if applicable
- Saving throw type or defense check, if applicable
- Attack roll requirement, if applicable
- Duration
- Concentration requirement
- Status effects applied
- Whether the effect is instant, recurring, sustained, or triggered
- Upcast scaling behavior
- Combat log text
- Tooltip summary
- AI usage category

Suggested action categories:

- Action: consumes the normal spell/action use for the turn.
- Quick action: can be used as a smaller secondary action if the combat system supports it.
- Reaction: used in response to a trigger, such as being attacked.
- Weapon rider: cast first, then applies to the next successful weapon hit.
- Sustained command: an already-active spell can produce an effect each turn without recasting, if the spell says so.

If the game does not support quick actions, convert quick-action healing spells into normal actions but give them better range or slightly lower spell point cost only if needed for balance.

If the game does not support reactions, defensive reaction spells such as Shield should be implemented as a temporary defensive stance or instant triggered defensive popup. The preferred implementation is reaction-based if possible.

Concentration
=============
Several spells require concentration. Concentration is a balancing mechanic for strong ongoing spells.

Rules for concentration:

- A character may maintain only one concentration spell at a time.
- Casting a new concentration spell ends the previous concentration spell from that caster.
- If the caster is defeated, incapacitated, stunned, or otherwise unable to act, concentration ends.
- If the combat system supports concentration break checks, taking damage should have a chance to break concentration.
- If concentration break checks are not implemented yet, use the simpler rule: concentration only ends when duration expires, caster is disabled, caster dies, or caster starts another concentration spell.

Concentration spells should show a clear active status indicator on the caster and on affected targets or areas.

Durations
=========
To keep combat readable, most ongoing spells should use short tactical durations.

Recommended standard durations:

- Instant: resolves immediately.
- 1 round: short disable or burst control.
- 3 rounds: standard combat buff, debuff, aura, or hazard.
- Encounter: use sparingly for simple passive buffs such as Mage Armor, Longstrider, Aid, or trap-like effects if that fits the dungeon crawler structure.

Do not use long tabletop durations such as 1 minute, 10 minutes, 1 hour, or 8 hours in the first implementation. Convert them into 3 rounds or encounter duration as appropriate.

Saving Throws and Attack Rolls
==============================
The game may not use tabletop-style saving throws. If it does, map spells to standard defenses.

Recommended saving throw/defense mapping:

- Dexterity / Reflex: avoid explosions, cones, lines, slippery ground, lightning, fireballs.
- Constitution / Fortitude: resist thunder blasts, poison-like effects, endurance pressure.
- Wisdom / Willpower: resist charm, fear, mental control, divine pressure.
- Strength / Athletics: resist being pushed, restrained, knocked prone, or dragged.

If the game uses a simplified defense system, use:

- Physical defense for restraint, push, prone, and bodily effects.
- Reflex defense for area damage.
- Will defense for fear, charm, sleep, hold, bane, and similar mental effects.

General resolution rules:

- If a spell says "save for half," a successful save halves the damage and prevents secondary effects unless the spell says otherwise.
- If a spell says "save or status," a successful save prevents the status.
- If a spell uses a spell attack, the caster rolls against target defense.
- If a spell automatically hits, it should be balanced by lower damage or spell point cost constraints.

Recommended Status Effects
==========================
Implement or map the following status effects. These should be shared across spells.

Exposed
-------
The next attack against the target has improved accuracy, advantage, or increased critical chance, depending on the combat system. Once triggered, Exposed is removed unless the spell says it lasts longer.

Revealed
--------
The target cannot benefit from invisibility, stealth, or hidden status. Attacks against the target may also receive a small accuracy bonus if desired.

Restrained
----------
The target cannot move or has severely reduced movement. Attacks against the target may gain an accuracy bonus. The target can still act unless the game chooses to make Restrained stronger.

Held
----
The target cannot act for the duration. Melee hits against a Held target should be empowered if the engine supports this. This is a strong status and should usually last 1 round in the slim version.

Prone
-----
The target loses movement or must spend part of its next turn standing. Melee attacks against the target may be easier; ranged attacks may be harder depending on existing combat rules.

Frightened
----------
The target suffers attack penalties and may be unable or unwilling to move closer to the caster/source.

Charmed/Stunned
---------------
For Hypnotic Pattern and similar effects, use a simplified control status: the target skips its next action or cannot act for 1 round. Damage should break the effect if specified.

Asleep
------
The target skips its turn until the duration ends or until it takes damage. Best used only against low-health enemies.

Obscured
--------
Creatures inside the affected area are difficult to target from outside. Ranged attacks into, out of, or through the area suffer an accuracy penalty.

Marked
------
The target is linked to a specific attacker. The mark may cause extra damage from that attacker, penalize attacks against others, or both, depending on the spell.

Slowed
------
The target has reduced movement. This is useful for Spirit Guardians, Spike Growth, and terrain effects.

Temporary HP
------------
Extra hit points that are lost before normal HP. They do not stack unless the game already has a stacking rule. By default, replace weaker temporary HP with stronger temporary HP.

Damage Types
============
Support the following damage types at minimum:

- Fire
- Lightning
- Thunder
- Radiant
- Necrotic
- Psychic
- Force
- Piercing

If the game does not yet distinguish damage types mechanically, still include damage types in the spell data and combat log so resistances and vulnerabilities can be added later.

Area Shapes
===========
Implement reusable area targeting shapes:

- Single target
- Self
- Ally target
- Enemy target
- Small radius burst
- Large radius burst
- Cone
- Line
- Aura around caster
- Ground-targeted persistent zone
- Trap zone

Approximate sizes should be tuned for the game's grid or spatial system.

Recommended tactical sizes:

- Small area: affects roughly 2-4 tightly grouped units.
- Large area: affects roughly 4-8 units if positioned well.
- Cone: short but wide frontal area.
- Line: long narrow path.
- Aura: centered on the caster and moves with caster if the spell says so.
- Ground zone: fixed area that remains for the duration.

Upcasting Rules
===============
Each spell has a specific upcast rule. Use the individual spell descriptions below as source of truth.

General defaults:

- Damage spells usually gain one extra damage die per spell level above base.
- Healing spells usually gain one extra healing die per spell level above base.
- Multi-target buffs/debuffs usually gain one extra target per spell level above base.
- Area control spells usually gain area size or duration, not both, unless balance allows it.
- Strong disables should generally gain extra targets, not longer disable duration.
- Defensive reaction spells do not need scaling unless the game requires every spell to scale.

If a spell's official tabletop upcasting is awkward for a dungeon crawler, use the simplified upcast rule from this document.

Class Spell Lists
=================
Each class has exactly 10 curated spells in the initial slim implementation.

A spell can appear on multiple class lists. Implement it once, then reference it from all allowed classes.

The following lists are the implementation source of truth.

Type: Healing

Concentration: Yes

Type: Recurring damage

Concentration: No

Base level: 2

Type: Disable

Effect: Target makes a Will/Wisdom save. On failure, target becomes Held.
Upcast: +1 target per spell level above 2nd.
Notes: If enemy creature types are not implemented, allow it to affect most non-boss enemies. Bosses should resist or have shortened effect.

9. Spirit Guardians
Base level: 3
Cost: 5 SP at 3rd level
Action type: Action
Target: Aura around caster
Type: Sustained area damage and control
Duration: 3 rounds
Concentration: Yes
Effect: Enemies entering the aura or starting their turn inside it take 3d8 radiant or necrotic damage, save for half. Enemies inside are Slowed.
Upcast: +1d8 damage per spell level above 3rd if higher spell levels are later supported.

10. Mass Healing Word
Base level: 3
Cost: 5 SP at 3rd level
Action type: Quick action if supported; otherwise Action
Target: Up to 6 allies at range
Type: Multi-target healing
Effect: Each target heals 1d4 + caster spell stat.
Upcast: +1d4 healing per spell level above 3rd if higher spell levels are later supported.

Recommended Spell Templates
===========================
Implement these reusable templates first, then define individual spells using them.

Used by: Cure Wounds, Healing Word

Used by: Magic Missile

5. Multi-Ray Spell Attack
Used by: Scorching Ray
Required behavior: Generate multiple attack rolls, allow split targeting, apply damage per hit.

6. Cone Damage
Used by: Burning Hands, Thunderwave if implemented as cone
Required behavior: Select cone, apply save for half, apply optional push.

7. Burst Area Damage
Used by: Fireball, Shatter, Hail of Thorns
Required behavior: Select area, affect all valid enemies, save for half.

8. Line Damage
Used by: Lightning Bolt
Required behavior: Select line direction or target line, affect all enemies in line, save for half.

9. Ally Buff
Used by: Bless, Shield of Faith, Barkskin, Heroism, Divine Favor, Longstrider, Mage Armor, Aid, Haste
Required behavior: Apply status to ally/self, track duration, enforce concentration if needed.

10. Enemy Debuff
Used by: Bane, Compelled Duel, Heat Metal, Hunter's Mark
Required behavior: Apply status after save if needed, track source caster, track duration.

11. Disable/Control
Used by: Hold Person, Hideous Laughter, Hypnotic Pattern, Sleep
Required behavior: Apply action denial or restricted action state, handle damage break if relevant, handle boss resistance.

12. Persistent Ground Hazard

15. Weapon Rider

Each spell should have a clear tooltip containing:

- Spell name

- Base level
- Current spell point cost
- Action type
- Range
- Targeting rules
- Damage/healing amount
- Duration
- Concentration requirement
- Upcast effect
- Short tactical description

During targeting, the UI should show:

- Valid targets or valid ground tiles
- Area preview for AoE spells
- Affected enemies/allies before confirmation
- Expected damage/healing range if the game supports previews
- Spell point cost before confirmation
- Warning if casting breaks current concentration

During combat resolution, the combat log should report:

- Caster name
- Spell name
- Cast level and spell point cost
- Targets affected
- Damage/healing dealt
- Saves succeeded or failed

- Concentration started or ended
- Upcast effect if relevant

Visual distinction by class:

- Cleric: radiant, gold/white, holy symbols, protective light.
- Druid: vines, leaves, moonlight, storm clouds, natural terrain.
- Wizard: precise arcane geometry, runes, classic elemental effects.
- Bard: sound waves, color, charm motifs, musical resonance.

- Paladin: weapon glow, radiant smite flashes, defensive auras.
- Ranger: thorn bursts, marks, arrows, traps, fog, natural movement.

AI Usage Guidelines
===================
Enemy or companion AI should understand broad spell categories.

Suggested AI categories:

- Emergency heal: use when ally is low HP.
- Efficient heal: use when healing will not be wasted.
- Finish target: use single-target damage on low HP enemy.
- AoE damage: use when multiple enemies are clustered.
- Control cluster: use when several enemies can be disabled or slowed.
- Buff opener: use early in combat if expected fight length is long enough.
- Defensive reaction: use when it prevents meaningful damage.
- Escape/mobility: use when threatened in melee or to reach advantageous position.
- Anti-caster: use Silence or control on enemy spellcasters.
- Mark priority target: use Hunter's Mark or similar on durable/high-priority enemies.

AI should avoid:

- Wasting AoE on a single weak target unless necessary.
- Healing targets near full HP.
- Casting concentration spells that immediately overwrite a better active concentration spell.
- Placing hazards where they mostly hurt allies.
- Using control spells on immune bosses unless the spell has partial effect.

Boss and Elite Handling
=======================
Hard control effects can trivialize bosses. Use special rules for elite and boss enemies.

Recommended approach:

- Bosses may be immune to full action-denial statuses such as Held, Asleep, and Charmed/Stunned.
- If a boss resists full control, apply a weaker fallback effect instead, such as Slowed, Exposed, reduced accuracy, or reduced next action effectiveness.
- Elites may have advantage/bonus on saves against hard control or reduced duration.
- Damage portions of spells should usually still apply unless the boss has resistance or immunity.

Examples:

- Hold Person on boss: boss is not Held, but becomes Slowed or Exposed for 1 round on failed save.
- Hypnotic Pattern on boss: boss does not lose full turn, but suffers attack penalty for 1 round.
- Sleep on boss: no effect or minor accuracy penalty if failed save.

Balance Guidelines
==================
Use these rough balance anchors.

1st-level spells:

- Single-target damage: around 3d6 to 4d6 if it requires attack/save.
- Area damage: around 2d8 or 3d6.
- Healing: around 1d4 to 1d8 + spell stat.
- Buff/debuff: 3 rounds, concentration, moderate bonus or penalty.

2nd-level spells:

- Single-target/multi-hit damage: around 3 rays of 2d6, or recurring 2d8.
- Area damage: around 3d8.
- Control: stronger area or stronger single-target disable.
- Terrain: meaningful but avoid automatic repeated hard lockdown.

3rd-level spells:

- Large AoE damage: around 8d6.
- Strong recurring damage: around 3d8 to 3d10 per round with concentration.
- Major buff: Haste-level effects, concentration required.
- Multi-target emergency healing: useful but not overpowering.

Concentration should be the main limiter for powerful ongoing spells. Spell points should be the main limiter for burst spells.

Character Level Gating
======================
For full casters:

- Character levels 1-2: allow 1st-level spells.
- Character levels 3-4: allow 1st- and 2nd-level spells.
- Character levels 5-6: allow 1st-, 2nd-, and 3rd-level spells.

Full casters in this document:

- Cleric
- Druid
- Wizard
- Bard
- Sorcerer

For half casters:

- Character level 1: no spells, unless the game intentionally grants early magic.
- Character levels 2-4: allow 1st-level spells.
- Character levels 5-6: allow 1st- and 2nd-level spells.

Half casters in this document:

- Paladin
- Ranger

If the game wants every listed class to feel magical from level 1, it is acceptable to let Paladin and Ranger access a limited subset of 1st-level spells earlier than tabletop. If doing so, document that this is an intentional game adaptation.

Prepared vs Known Spell Handling
================================
For this slim version, do not implement the full tabletop distinction between prepared casters and known-spell casters unless already present.

Preferred simplified approach:

- Each class has access to its curated 10-spell kit.
- At any given time, a character equips a limited number of spells into active combat slots.
- Spell slots in the UI are not spell slots in the tabletop sense; they are prepared/loaded spell buttons.
- Spell point cost controls usage during combat.

Suggested active spell loadout sizes:

- Levels 1-2: 3-4 active spells
- Levels 3-4: 4-5 active spells
- Levels 5-6: 5-6 active spells

This keeps combat manageable while preserving choice.

If the game does not use active spell loadouts, allow all 10 class spells to be available once unlocked. However, this may overload the UI and reduce class differentiation.

Class Flavor Notes
==================
Cleric should feel like:
- The most reliable healer.
- Strong against enemies through radiant pressure.
- Durable support with Bless, Shield of Faith, and Spirit Guardians.

Druid should feel like:
- The best terrain controller.
- A nature caster who shapes the battlefield.
- Flexible between healing, elemental damage, and area denial.

Wizard should feel like:
- The most versatile arcane toolkit.
- Strong area damage and control.
- Fragile but protected by Shield, Misty Step, and control spells.

Bard should feel like:
- A support-disruptor hybrid.
- Capable of healing, disabling, revealing, and sonic/psychic pressure.
- Less direct blasting than Wizard/Sorcerer, but more control and support.

Sorcerer should feel like:
- The cleanest blaster.
- Strong elemental burst damage.
- Mobile and self-protective.
- Less broad utility than Wizard but more direct destructive identity.

Paladin should feel like:
- A melee holy warrior.
- Uses spells to empower attacks, protect allies, and hold enemy attention.
- Has healing, but not as much as Cleric.

Ranger should feel like:
- A hunter and skirmisher.
- Marks priority targets.
- Controls space with traps, thorns, fog, and silence.
- Has some healing, but not as much as Cleric or Druid.

Acceptance Criteria
===================
The spell implementation is acceptable when the following are true:

1. Each listed class has exactly the curated 10 spells available in the data.
2. Shared spells are implemented once and referenced by multiple classes.
3. Spell point costs follow the 2 / 3 / 5 cost curve for spell levels 1 / 2 / 3.
4. Upcasting works for all spells that list upcast scaling.
5. Concentration prevents multiple concentration spells from the same caster.
6. Area spells preview their affected area before casting.
7. Healing spells cannot target invalid enemies unless explicitly allowed by the game's rules.
8. Damage spells cannot target invalid allies unless friendly fire is intentionally enabled.
9. Buff and debuff durations tick down correctly by round.
10. Status effects are visible in the UI and described in tooltips.
11. The combat log clearly describes spell results.
12. Bosses and elites are protected against hard-control abuse.
13. Spell descriptions are concise enough for players but detailed enough to understand upcasting and concentration.
14. Paladin and Ranger do not receive 3rd-level spells in the level 1-6 implementation unless intentionally house-ruled.
15. The implementation remains data-driven enough that future spells can be added without rewriting combat logic.

Testing Checklist
=================
Basic tests:

- A character cannot cast a spell without enough spell points.
- A character pays the correct spell point cost when casting.
- Upcasting charges the correct higher cost.
- Upcast damage/healing/targets apply correctly.
- Concentration spell A ends when concentration spell B is cast by the same caster.
- Concentration ends when the caster is defeated.
- Non-concentration buffs can coexist with concentration buffs unless another rule prevents it.

Targeting tests:

- Single-target ally spells only select valid allies.
- Single-target enemy spells only select valid enemies.
- AoE previews match actual affected units.
- Line spells affect every enemy in the line.
- Cone spells affect enemies inside the cone only.
- Ground hazards trigger correctly when enemies enter or start inside.
- Teleport spells reject blocked or invalid destinations.

Status tests:

- Exposed is consumed after the next eligible attack.
- Restrained reduces/prevents movement.
- Held prevents action for the intended duration.
- Prone applies its movement/action penalty.
- Frightened applies attack/movement penalties.
- Obscured affects ranged targeting.
- Revealed prevents stealth/invisibility benefits.
- Marked effects only benefit or constrain the correct source/target.

Spell-specific tests:

- Magic Missile never misses and can split darts.
- Shield can prevent a hit if the defense bonus is enough.
- Fireball damages all valid enemies in the area and allows saves for half.
- Healing Word works at range and as quick action if quick actions exist.
- Spirit Guardians follows the caster and damages enemies correctly.
- Spike Growth damages enemies when they move through the area.
- Hunter's Mark only adds damage from the Ranger who applied it.
- Smite spells apply only to the next successful weapon hit.
- Haste does not allow unintended extra full spellcasting unless specifically designed.
- Silence meaningfully prevents or penalizes enemy spellcasting.

Future Extension Notes
======================
After this first pass, future expansions can add:

- Cantrips as basic magical attacks.
- Subclass-specific spell additions.
- Higher-level spells.
- Ritual and exploration magic.
- Spell schools and resistances.
- Metamagic for Sorcerer.
- Channel Divinity-like features for Cleric/Paladin.
- Wild Shape or nature summons for Druid.
- Bardic Inspiration as a separate class feature.
- Wizard spellbook mechanics.
- More advanced AI spell planning.

Keep the first implementation narrow, readable, and easy to balance. The main success criterion is that each spellcasting class feels distinct in combat while the underlying implementation remains compact and reusable.
