Current source files to compare against:
- Resource/component item templates: src/scripts/content/items/materials.js

1. What counts as a resource

The game currently has two overlapping resource styles:

Party resources/components:
- type: "component"
- stackable: true
- resourceInventory: "party"
- tags include "component", "crafting", "party-resource"
- used by partyResourceCount, quest turn-ins, and crafting/profession requirements

Field-use resource consumables:
- type: "consumable"
- often gathered from furniture
- usually have use.status or healing use
- not all of them are "party-resource" components

The runtime does not have a separate resource bucket UI yet. Component items are normal item templates with stack behavior and party-resource tags.

2. Registered party-resource component items

These are currently registered in materials.js, though green-vines and black-briar-root are later re-registered by old-lady.js with nearly the same component data.

Herbs and plant reagents:
- green-vines: Green Vines. Common herb/vine. Tags include alchemy, plant, herb, forest, forage, food, healing, quest:green-vines.
- black-briar-root: Black Briar Root. Uncommon herb/root. Tags include alchemy, plant, root, forest, forage, magic-reagent, quest:black-briar-root.
- medicinal-herb: Medicinal Herb. Common herb bundle. Tags include alchemy, plant, herb, forest, forage, healing, food.

Undead/old-guardroom monster parts:
- bone-dust: Bone Dust. Common monster part, bone dust. Tags include alchemy, undead, skeleton, old-guardroom, crypt.
- cracked-rib-bone: Cracked Rib Bone. Common monster part, bone shard. Tags include undead, skeleton, old-guardroom, crypt.
- skull-fragment: Skull Fragment. Common monster part, bone fragment. Tags include undead, skeleton, old-guardroom, crypt.
- grave-wax: Grave Wax. Uncommon alchemy reagent. Tags include magic-reagent, undead, old-guardroom, crypt, relic.

Beast monster parts:
- beast-hide: Beast Hide. Common leather/monster part. Tags include beast, hide, leather, repair, upgrade.
- beast-claw: Beast Claw. Common monster part. Tags include beast, claw, bone, alchemy, trophy.
- beast-fang: Beast Fang. Common monster part. Tags include beast, fang, bone, alchemy, trophy.
- monster-blood: Monster Blood. Common alchemy reagent. Tags include blood, reagent, monster-part.
- raw-meat: Raw Meat. Common food ingredient. Tags include food, beast, monster-part, meat, cook.

Building/repair resources:
- iron-scrap: Iron Scrap. Common metal/building material. Tags include building, metal, iron, repair, upgrade, trade-good.
- wood-bundle: Wood Bundle. Common wood/building material. Tags include building, wood, repair, trade-good.
- stone-chip: Stone Chip. Common stone/building material. Tags include building, stone, repair, trade-good.
- cloth-scrap: Cloth Scrap. Common cloth repair material. Tags include cloth, repair, trade-good.
- leather-scrap: Leather Scrap. Common leather repair material. Tags include leather, repair, upgrade, trade-good.

Arcane/construct resources:
- crystal-shard: Crystal Shard. Uncommon arcane reagent. Tags include alchemy, arcane-reagent, magic-reagent, crystal, upgrade.
- arcane-gear: Arcane Gear. Uncommon arcane reagent. Tags include construct, arcane-reagent, magic-reagent, metal, repair, upgrade.

3. Registered field-use resource consumables

These are in equipment.js and are harvestable/hidden in furniture. They are useful resource-like items, but they are not currently party-resource components unless another later file overwrites the id.

- berry: heals 1 HP.
- bitter-root: grants poison resistance until home.
- cave-salt: grants +1 saving throws until home.
- bone-charm: grants necrotic resistance until home.
- glowcap: grants +5 ft speed until home.
- spider-silk: grants +1 attack rolls until home.
- sacred-ash: grants +1 AC and necrotic resistance until home.

Merged duplicate ids:
- medicinal-herb starts as a healing consumable in equipment.js, then materials.js merges it into a component. It is now both a party resource and a usable 1d4 healing herb.
- crystal-shard starts as a use-status consumable in equipment.js, then materials.js merges it into a component. It is now both a party resource and a usable damage-bonus shard.
- green-vines and black-briar-root are registered in materials.js, then old-lady.js merges in quest-specific tags/flavor. They remain component party resources and also count for the Old Lady quest chain.

4. Automatic monster material drops

4a. Farmable dungeon resource nodes

Resource nodes are furniture templates with kind: "resource-node" and a resourceNode component. They are loaded from resource-nodes.js and placed by createDungeonObjects as a separate capped pass, not as normal room clutter.

Default generation rules:
- Generated dungeons try to place 1-2 resource nodes total, depending on available theme-matching node types and open wall-adjacent room cells.
- Themes can override this with resourceNodes or resourceNodeSpawns, for example { min: 0, max: 3, chance: 0.75 }. Setting it to false disables node spawning.
- Themes can also use resourceNodesBySize or resourceNodeSpawnsBySize for size-specific ranges. These theme-specific size ranges override the generic dungeon-size range.
- Dungeon sizes can override ordinary theme defaults too. Insane size currently requests 8-12 resource nodes unless the theme has its own size-specific range.
- Themes can use resourceNodeTagGroups or resourceNodeIds to choose nodes separately from normal furniture. If neither exists, nodes fall back to normal furnitureTagGroups.
- Old Guardroom currently allows dungeon/ruin/stone resource nodes. Forest of the Beasts currently allows forest/wilds/plant/wood resource nodes.
- Nodes default to placement: "wall-adjacent" so they tend to appear along dungeon walls.

Interaction rules:
- Only one party attempt is allowed per node. Once gathered, the object is spent even if the check fails.
- The active hero makes the node's configured ability/skill check.
- A success grants the base quantity. Every 5 points above the DC adds +1 quantity, up to the node max. A natural 20 adds +1, still capped by maxQuantity.
- The activity advances dungeon time using the node's configured timeSeconds.
- Component rewards go into the shared party resource satchel through addItemToInventory.

Current resource nodes:
- stone-outcrop: Stone Outcrop. CON Athletics DC 12, 20 minutes. Rewards stone-chip, 1-5.
- ore-vein: Ore Vein. STR Athletics DC 14, 30 minutes. Rewards iron-scrap, 1-4.
- coal-seam: Coal Seam. STR Athletics DC 12, 25 minutes. Rewards coal-chunk, 1-5.
- gem-seam: Gem Seam. INT Investigation DC 15, 25 minutes. Rewards crystal-shard, 1-3.
- herb-patch: Wild Herb Patch. WIS Medicine DC 12, 10 minutes. Rewards medicinal-herb, 1-4.
- vine-thicket-node: Vine Thicket. WIS Nature DC 10, 10 minutes. Rewards green-vines, 1-5.
- briar-root-node: Black Briar Root Cluster. WIS Nature DC 15, 15 minutes. Rewards black-briar-root, 1-3.
- fallen-timber-node: Fallen Timber. STR Athletics DC 12, 20 minutes. Rewards wood-bundle, 1-4.

Embervein Deepworks mining profile:
- This theme uses exact resourceNodeIds for stone-outcrop, ore-vein, and coal-seam so the larger node count stays focused on stone-chip, iron-scrap, and coal-chunk farming.
- Size-specific resource-node ranges: small 4-8, medium 5-10, large 10-15, massive 15-20, insane 20-25.

When a monster drops loot, combat-map.js calls addMonsterMaterialDrops(monster) before creating the loot pile. It checks the monster id/base id/template id and tags.

Undead/skeletal/skeleton drop table:
- bone-dust: 18 percent
- cracked-rib-bone: 8 percent
- skull-fragment: 3.5 percent
- grave-wax: 4 percent if the monster also has old-guardroom, otherwise 2 percent

Beast drop table:
- beast-hide: 22 percent
- beast-claw: 12 percent
- beast-fang: 12 percent
- monster-blood: 10 percent
- raw-meat: 18 percent

Construct drop table:
- iron-scrap: 28 percent, quantity 1d2
- arcane-gear: 10 percent
- crystal-shard: 6 percent

Worn metal armor cue:
- iron-scrap: 4.5 percent, or 8 percent for bosses
- Applies to non-beast, non-plant, non-elemental monsters whose equipment, name, id, role, tags, or specials imply worn metal armor or shields. Current cues include armor, armored, plate, mail, chain, shield, shieldbearer, tower shield, knight, sentinel, soldier, halberdier, pikeman, arbalester, and crossbowman.

Fitting elemental coal cue:
- coal-chunk: 5.5 percent, or 10 percent for bosses
- Applies to elementals whose identity, tags, name, role, or specials imply coal, soot, cinder, ember, ash, smoke, fire, lava, magma, furnace, slag, earth, stone, or ore.

There are currently no construct-tagged monsters registered in the loaded monster packs, so the construct table is ready but unused.

7. Quest-specific monster resource drops

old-lady.js can add extraLoot during quest progress checks:

- old-guardroom-relic: added to old-guardroom monsters for the Old Lady relic quest. This is a treasure/quest item, not a component, but it has component metadata for relic-scholar style use.
- black-briar-root: added to Old Sergeant (oldSergeant) if the party has no black-briar-root during the relevant Old Lady quest chain.

These are not part of the normal addMonsterMaterialDrops table. They are quest hooks.

9. Current crafting/profession usage

crafting.js is currently a data stub, but it already defines how resources are meant to be consumed.

Professions:
- alchemist accepts alchemy, reagent, herb, poison, venom, blood, dust, ash, oil, essence, extract, crystal, monster-part, magic-reagent.
- herbalist accepts herb, plant, root, flower, mushroom, food, healing, nature.
- cook accepts food, meat, herb, plant, healing.
- blacksmith accepts metal, iron, steel, repair, upgrade, building.
- relic-scholar accepts relic, old-guardroom, arcane-reagent, magic-reagent, undead, bone.

Recipes/stubs:
- old-lady-hearty-soup: needs 2 healing herbs and 1 food/meat component.
- basic-healing-potion: needs 2 common herbs and 1 alchemy/reagent component.
- repair-armor-iron-scrap: needs 3 iron repair materials.

10. Adding new resource drops

For tag-wide monster drops, edit addMonsterMaterialDrops in combat-map.js:

if (ids.has("construct")) {
  add("iron-scrap", { chance: 0.28, quantityDice: { count: 1, sides: 2 } });
}

For one monster only, use extraLoot on its monster template:

extraLoot: [
  { kind: "item", itemId: "black-briar-root", quantity: 1, chance: 0.25 },
]

For a furniture resource, add a component in dungeon-furniture-pack.js:

components: [
  C.harvest("medicinal-herb", { dc: 10, chance: 0.5 }),
]

or for hidden loot:

components: [
  C.hiddenLoot({ dc: 13, item: "crystal-shard" }),
]

11. Testing checklist

- Confirm the item id exists after the final index.html load order.
- Confirm stackable/resourceInventory if it is meant to be a party resource.
- Confirm monster tags match the automatic table you expect.
- Kill several matching monsters to verify chance-based drops.
- Inspect furniture and verify the investigation DC/chance path.
- For quest drops, test with the relevant Old Lady quest state active.
